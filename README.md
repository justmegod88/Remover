# 렌즈 착용 영상 코치 — 시험 버전

기존 착용 시뮬레이터를 덮어쓰지 않는 별도 페이지입니다. 완성된 화면과 실제 API 연결 코드가 포함되어 있습니다. API 키/배포가 제공되지 않아 실제 AI 응답과 임상적 코칭 정확도는 검증하지 않았습니다.

## 현재 되는 일

- 영상 선택, 브라우저가 지원하는 경우 소리 없이 15초 촬영
- 3~30초, 100MB 이하 영상에서 12개 시점을 균등 추출
- 전송 전 장면 확인/제외, 영상의 해당 시점 다시 보기
- 사용자 동의 후 선택 장면만 API에 전송
- 서버의 실제 응답으로 근거 장면 최대 3개, 다음 행동 한 가지, 판단 한계를 표시
- 브라우저가 지원하면 한국어 음성 읽기
- 서버 미연결/권한/시간초과 시 명확한 오류. 가짜 분석 결과 없음

정지 장면 간격 사이 동작, 투명 렌즈 앞뒤·위생·실제 착용 성공·안전성은 확정하지 않습니다. 숫자 점수나 mm 단위 교정 지시는 제공하지 않습니다. 영상은 모델에 직접 전달되는 것이 아니라 선택된 사진으로 변환됩니다. 자동으로 '실패 순간'을 검출했다고 표시하지 않습니다.

## 배포 순서

1. 이 폴더 전체를 새 Vercel 프로젝트로 배포합니다. Framework Preset은 Other, Build Command와 Output Directory는 기본값을 사용합니다. `index.html`과 `api/analyze.js`의 위치를 그대로 유지합니다. 기존 프로젝트를 교체할 필요는 없습니다.
2. Vercel 프로젝트 Settings → Environment Variables에 아래 값을 추가하고 다시 배포합니다.

| 변수 | 값 |
|---|---|
| OPENAI_API_KEY | 본인 OpenAI API 키. HTML이나 GitHub에 입력 금지 |
| OPENAI_MODEL | 이미지 입력과 Responses JSON Schema 출력을 지원하며 본인 계정에서 접근 가능한 모델 ID. 공식 문서 예시의 gpt-6-astra 등. 계정 접근 여부는 별도 확인 |
| COACH_ACCESS_CODE | 테스트 사용자에게만 공유할 긴 임의 접속 코드 |
| ALLOWED_ORIGINS | 별도 GitHub Pages 등에서 접속하는 경우 정확한 원본 주소. 예: https://justmegod88.github.io . 여러 개는 쉼표로 구분. 경로·마지막 / 제외 |

3. Vercel HTTPS 주소를 열어 '테스트 연결 설정'의 접속 코드를 입력합니다. 같은 서버에 HTML을 배포했다면 서버 주소 칸은 비워둡니다.
4. HTML을 다른 사이트에 둘 경우 서버 주소에 `https://배포주소/api/analyze`를 입력합니다. 파일을 직접 열면 카메라/CORS가 제한될 수 있으므로 실제 분석은 HTTPS 페이지에서 테스트합니다. iOS 내장 미리보기 대신 Safari에서 배포 주소를 사용하세요.
5. 본인의 짧은 테스트 영상을 선택 → 장면 준비 → 장면 확인 → 동의 → 코칭 받기를 누릅니다.

API 이용은 별도 과금입니다. ChatGPT 구독과 별개이며 이 패키지에는 유료 키가 포함되지 않습니다. 이 코드가 기존 Vercel/안경 제거 프로젝트의 키나 엔드포인트를 자동 사용하지 않습니다.

## 데이터/운영 범위

영상 원본과 추출 장면은 페이지 메모리에만 있으며 로컬 저장소에 기록하지 않습니다. 지우기/새로고침 시 앱의 참조를 해제합니다. 서버는 요청/이미지/답변을 파일 또는 DB에 저장하거나 로그로 출력하지 않습니다. 원본 휴대폰 파일은 삭제하지 않습니다. API에는 선택한 이미지와 입력한 맥락을 전달하고 store:false를 설정하지만 이것이 제공자의 모든 로그/보관을 없앤다는 의미는 아닙니다. 운영자의 호스팅·API 데이터 처리 조건을 따로 검토해야 합니다.

공유 접속 코드는 소규모 비공개 시험용입니다. CORS는 사용자 인증이 아니며 접속 코드가 공유되면 비용 발생을 막지 못합니다. 공개 운영 전 사용자 인증, 영속적인 사용량 제한, 비용 관리, 동의/개인정보 정책, 전문가 검수 지식 기반 및 실제 영상 평가가 필요합니다. 서버/프롬프트만으로 코칭 정확도가 보장되지 않습니다.

안경사/안과 전문가가 정상 및 실패 사례, 손 가림, 저조도, 안경 착용, 무관한 영상, 통증을 말하는 질문을 검토한 뒤 일반 소비자에게 제공하세요. 좌우 손가락 식별 및 속도·깜박임 평가는 정지 장면만으로 신뢰할 수 없어 단정하지 않도록 구성했습니다.
