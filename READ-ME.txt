착용·제거 연습 + 영상 코칭 수정본

적용 방법
ZIP을 풀고 index.html, api/analyze.js, package.json, vercel.json을 기존 GitHub 저장소의 같은 위치에 덮어쓰세요. api 폴더 구조를 유지하세요.
Vercel에 연결된 저장소에 올리면 배포가 시작됩니다. index.html만 바꾸면 서버 오류 설명 개선은 적용되지 않습니다.
API 키와 테스트 접속 코드는 포함하지 않았습니다. 분석이 되던 기존 Vercel 환경변수 값을 유지하세요. 이번 수정에 모델 변경은 필요하지 않습니다.

변경 사항
- 제거 화면의 홍채 질감, 피부 명암, 눈꺼풀, 속눈썹, 아래 눈꺼풀을 잡는 손가락을 수정했습니다.
- 연습 화면을 덮던 작은 동영상 창을 없애고 ‘영상으로 보기’ 메뉴에서 착용/제거 영상을 선택하도록 했습니다. 영상 코칭 메뉴는 별도로 유지합니다.
- YouTube에 사이트 출처가 전달되도록 Referrer-Policy를 수정했습니다. 임베드가 차단된 경우 YouTube로 직접 여는 링크가 있습니다.
- 제거 영상도 착용으로 보내던 오류를 고쳤습니다.
- 선택 해제한 장면 때문에 결과와 근거 사진이 어긋나던 오류를 고쳤습니다.
- 최대 전송 크기를 1280에서 960px로 조정하고 장면별 압축을 적용했습니다. 원본보다 확대하지 않습니다.
- 관찰하기 어려운 장면에서 눈을 감았다고 단정하거나 일반적인 조언을 반복하지 않도록 요청 지침을 보강했습니다. AI의 오판을 완전히 막을 수는 없습니다.
- 모델 접근, API 키, 사용 한도, 답변 길이 제한, 시간 초과를 다른 오류 코드로 표시합니다.

분석 실패에 대해 확인한 범위
현재 공개 페이지는 이전 index.html과 같은 파일인 것을 확인했습니다. 과거 실패 당시 서버 응답과 로그는 확보하지 못해 정확한 원인은 확정할 수 없습니다.
이전 품질 개선에서 장면 최대 해상도가 640에서 1280px로 커졌고, 모델 변경도 안내됐습니다. 처리 부담이나 모델 접근 문제는 가능한 원인이지만 확인된 원인은 아닙니다.
기존 서버는 여러 실패 원인을 같은 문구로 숨기고 있었습니다. 이 수정본에서 발생하는 오류에는 구분 코드가 표시됩니다.

확인한 테스트
모바일 390px 화면, 제거 눈꺼풀 조작, 영상 메뉴 전환/닫기, 영상에서 8장 추출, 장면 선택 해제 후 근거 사진 연결, 제거 모드 전송, 모의 AI 성공 응답과 실패 유형별 처리.
실제 유료 OpenAI 호출과 사용자 Vercel 환경변수는 확인하지 않았습니다. 모든 코칭은 정지 장면 기반이며 연속 동작이나 착용 성공·안전을 판정하지 않습니다.
