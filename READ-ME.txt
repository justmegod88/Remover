영상 코칭 품질 개선판

ZIP을 풀고 index.html, api/analyze.js, package.json, vercel.json을 기존 GitHub 저장소의 같은 위치에 올리세요. api 폴더 구조를 유지하세요.
기존 착용/제거 기능은 유지됩니다. API 키와 접속 코드는 파일에 포함되지 않습니다. 기존 Vercel 환경변수를 유지하세요.

개선: 장면 선택 해제 후 근거 사진 불일치 수정, 전송 최대 해상도 640 -> 1280px(원본 해상도 내), 용량 제한 압축, 불확실한 눈 감음 판단 억제, 근거 없는 관찰 채우기 금지, 자연스러운 한국어 코칭, 연결 오류 설명 개선.
모델 자체는 기존 OPENAI_MODEL 설정을 유지합니다. 상위 모델을 시험하려면 Vercel OPENAI_MODEL을 gpt-5.4로 바꾼 뒤 재배포하세요. 이미지 입력/Responses/구조화 출력을 지원합니다. API 비용이 증가할 수 있으며 정확도 개선이 보장되지는 않습니다.
이 패키지는 구문 및 모의 API 테스트용으로 검증했습니다. 유료 실제 AI 분석과 임상 정확도는 검증하지 않았습니다. 정지 장면 분석이며 실시간 영상 분석이 아닙니다.
